# Farshelf icon

The icon is a high-resolution reconstruction of the supplied Farshelf contact
sheet: blue and mint archive cards with a white photo frame and yellow sun.

- `AppIcon.icon` is the Icon Composer source for macOS 26 and later. Its artwork
  is a flattened PNG layer; the individual illustrated cards are not separate
  editable layers.
- `../AppIcon.icns` contains the same artwork at the sizes used by earlier
  macOS versions.
- `../../docs/logo.png` is the same icon with transparent corners for the README.
- `tray.png`, `tray-dim.png`, and `tray-paused.png` are menu-bar variants.

When changing the artwork, update the Icon Composer layer, all sizes in the
`.icns` file, the README logo, and the three menu-bar variants together.
